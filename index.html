Dashboard + 7 module

Mọi module theo cùng một quy trình an toàn: quét (chỉ đọc) → xem lại → xác nhận → chạy (có Hủy) → kết quả trước/sau.

M1

Tối ưu RAM

Giải phóng RAM đúng cách (không "ép xả" ảo): dọn bộ nhớ cache của tiến trình nền an toàn, hiển thị trước/sau bằng số đo thật.

M2

Dọn ổ cứng

Liệt kê file rác, cache, Downloads cũ… với mức rủi ro rõ ràng. Chỉ mục khuyến nghị được tick sẵn; mục rủi ro không bao giờ tick sẵn.

M3

Cập nhật Driver

Tìm và cài driver qua dịch vụ Windows Update chính thức (WUA). Tự sao lưu driver trước khi cài để rollback được.

M4

Thông số phần cứng

CPU, RAM, mainboard, GPU, ổ đĩa, pin… đọc qua CIM/registry/.NET — kèm chế độ che dữ liệu nhạy cảm khi chụp màn hình.

M5

Kiểm tra bảo mật

Trạng thái Defender, Windows Update, firewall, UAC, BitLocker… kèm khuyến nghị từng mục — không tự ý đổi cấu hình.

M6

Sức khỏe máy tính

Điểm sức khỏe 100 điểm theo công thức công khai: SMART ổ đĩa, nhiệt độ, lỗi hệ thống, thời gian boot — không đoán.

M7

Độ lão hóa phần cứng

Chu kỳ sạc pin, giờ bật nguồn, số lần ghi SSD, tuổi đời linh kiện — đánh giá trung thực thay vì hứa suông.

Chạy trong 3 bước

Không tải installer, không next-next-next, không cài thêm bất cứ thứ gì.

Mở PowerShell (Admin)

Nhấn Win + X rồi chọn Windows PowerShell (Admin) hoặc Terminal (Admin), chọn Yes ở UAC.

Dán lệnh một dòng

Dán lệnh irm … | iex ở phía trên rồi Enter. Script tự kiểm tra Windows 10/11, tự nâng quyền nếu thiếu.

App giao diện mở ra

Cửa sổ WPF tiếng Việt hiện Dashboard tổng quan + 7 module. Mọi thao tác nguy hiểm đều phải xác nhận 2 bước.

Trung thực với bạn: WinCare được phát triển và kiểm thử tĩnh (parse, 24 test Pester logic, 50 test smoke) trên môi trường phát triển Linux — runtime trên Windows thật chưa được kiểm chứng và các module hiển thị chip "Beta / chưa kiểm chứng runtime". Xem chi tiết trong TEST-REPORT.md.

Yêu cầu & tùy chọn

Chạy được ngay trên Windows chuẩn, không cần cài đặt thêm.

Yêu cầu hệ thống

  • Windows 10 1809 (build 17763) trở lên hoặc Windows 11, 64-bit
  • Windows PowerShell 5.1 (có sẵn) hoặc PowerShell 7+
  • Quyền Administrator — script tự xin UAC
  • Mạng chỉ dùng cho: Windows Update (tìm driver) và URL script
  • Dữ liệu app nằm tại %ProgramData%\WinCare — có nút xóa sạch trong phần Lịch sử
